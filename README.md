# 南向 Southbound

澳大利亚与新西兰技术工作者的准备工作台，发布于 [nz.yusenleo.top](https://nz.yusenleo.top)。

## 内容与交互

- 独立国家指南：签证路线、求职、英语、伴侣父母、留学和落地生活。
- 雇主雷达：国家、技术关键词、证据类型筛选与本地收藏。NZ 记录列出法律实体、NZBN 和核验快照；AU 区分岗位签证承诺、搬迁支持及历史资质。
- 澳新对比：相同维度并列规则，每行连接对应官方原文。
- 两国生活导航：求职、租房权益、税务、医疗、公共服务及论坛。
- 准备清单：稳定任务 ID、进度统计、按国家筛选、Markdown 导出，兼容旧版清单记录。
- 全站搜索：点击搜索或按 Cmd/Ctrl+K，支持方向键、回车和 Escape。

## 文件

`index.html` 提供静态外壳与首页；`content.js` 管理内容及来源；`app.js` 管理导航和本地交互；`styles.css` 与 `tokens.css` 提供响应式设计。无生产依赖、构建步骤、第三方字体或统计脚本。

保留旧入口 `#nz`、`#au`、`#compare`、`#resources`、`#checklist`，以及 `#job`、`#visa`、`#family` 的兼容映射。国家主题支持 `#nz/english`、`#au/routes` 等直接链接。

## 来源维护

最后人工核验：2026-10-22。关键规则以 INZ、Home Affairs、联邦法规、NZQA、ACS 与相关政府机构为依据。资料不是实时政策 API，接受 offer 和递交前需回原文复核。每次更新应同时修改来源说明、适用日期和页面核验记录；未来政策与已生效规则分别标注。

现行 NZ Green List 使用 `opsmanual/77204.htm` 入口。软件工程等组普通雇员 NZD 70/小时，年薪按合同工时折算。澳洲 2026–27 新提名的 CSIT 为 AUD 79,423，SSIT 为 AUD 146,576，另审市场工资与 earnings 构成。

政府名录查询、公司官方声明和历史名录不是同等级的担保证据。具体签约法律实体、认证状态及岗位支持需再次确认。

## 隐私

不发布个人姓名、当前雇主、学校、职业年限、收入、家庭身份等履历资料。清单和公司收藏只保存在访问者浏览器；不向本站服务器发送。托管服务与外部网站各有其隐私规则。

## 验证与发布

`node --check app.js`、`node --check content.js`、`git diff --check` 可运行静态检查。交互验收应覆盖国家主题、旧链接、搜索、筛选、收藏、清单导出、旧版迁移及本地存储不可用的情况；响应式检查覆盖 320、375、414、768 和桌面宽度。

`.github/workflows/pages.yml` 在推送 `main` 后部署。内容和交互已准备好后推送，核实 Actions 发布结果，并验证域名 HTTPS 与实际页面。不要把提交、推送或 Actions 成功单独等同于浏览器验收完成。
